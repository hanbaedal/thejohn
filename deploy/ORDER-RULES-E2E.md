## 사전 준비

- [ ] Node API 서버 재시작 완료 (vendors 인덱스: `loginId` + `vn_registered_by` 복합 unique)
- [ ] 테스트용 **관리자 A**, **관리자 B** (admin) 계정
- [ ] 테스트용 **업체** loginId 1개 (예: `testshop`)
- [ ] A·B 각각 상품 1개 이상 등록 (`pd_registered_by` = 각 관리자)
- [ ] SOLAPI는 선택 — 문자 실패해도 주문은 성공해야 함
